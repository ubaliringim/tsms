# ADR-007: Extensible Learning Object Model

Status: Accepted

Date: 2026-10-07

## Context

Learning needs reusable concepts, visuals, examples, questions, challenges, and summaries.

## Decision

Use typed structured learning objects with source provenance and publication state rather than giant HTML lesson blobs.

## Consequences

Support future object types through deliberate versioned schemas/renderers. Do not implement those schemas during Stage 0.

## Change policy

Do not silently violate this decision. Propose a superseding ADR if evidence requires a change.
